My Prompt Studio

세 스타일의 시각 규칙을 프롬프트로 옮긴 개인용 제작 도구입니다. 원작자의 그림을 복제하지 않고, 분석한 규칙으로 새로 생성하도록 안내합니다. 다른 사람의 그림을 그대로 옮기거나 자신의 것처럼 쓰지 마세요.

잘 쓰는 법

  • 스타일을 고르고 → 상황 카드를 누르고 → 4종을 복사합니다.
  • 영상은 모션 프롬프트를, 이미지는 이미지 프롬프트를 씁니다.
  • 결과가 어긋나면 간결 모드로 바꿔 다시 시도해 보세요.

새 스타일 추가

data/에 스타일 파일 하나를 만들고 MPS.register({...})로 등록한 뒤, index.html에 <script> 한 줄을 더하면 탭·프리셋·빌더·프롬프트가 자동으로 늘어납니다.
